Research — RBAC кітапханасы және аудит журналы
Орындаған: Амангелді Аяжан

1. Ұйым туралы
Бұл жобада компьютерлік жүйелердегі ақпараттық қауіпсіздік және пайдаланушылардың қолжетімділік құқықтарын басқару қарастырылады. Жүйеде әкімші (Admin), менеджер (Manager) және қарапайым пайдаланушы (User) сияқты рөлдер болады. Әр рөлге жеке құқықтар беріледі.

3. Анықталған проблема
Компьютерлік жүйеде пайдаланушылардың барлығына бірдей құқық берілсе, олар өздеріне тиесілі емес ақпаратты көріп, өзгертіп немесе өшіріп жіберуі мүмкін. Сонымен қатар кімнің қандай әрекет жасағанын анықтау қиын болады.

Қарапайым тілмен: Әр адам жүйеде тек өзіне рұқсат етілген әрекеттерді орындауы керек. Мысалы, қарапайым пайдаланушы әкімшінің ақпаратын өзгерте алмауы тиіс. Сондай-ақ жүйе кімнің не істегенін сақтауы қажет.

5. Ұсынылатын шешім
Бұл мәселені шешу үшін Java тілінде RBAC кітапханасы және аудит журналы жасалады. RBAC пайдаланушыларға рөлдер арқылы құқық береді және әр әрекеттің рұқсат етілгенін тексереді. Audit Log пайдаланушылардың жүйеде жасаған әрекеттерін тіркеп отырады.

Қарапайым тілмен: Жүйе адамның рөлін тексеріп, оған рұқсат етілген әрекеттерді ғана орындауға мүмкіндік береді. Ал кімнің не істегені арнайы журналға жазылады.

7. Жобаның мақсаты
Пайдаланушылардың қолжетімділік құқықтарын рөлдер арқылы басқаратын және олардың әрекеттерін тіркейтін қауіпсіз Java кітапханасын әзірлеу.

9. Жобаның міндеттері
Пайдаланушыларды тіркеу;
Пайдаланушыларға рөл тағайындау;
Admin, Manager және User рөлдерін құру;
Әр рөлге жеке құқықтар беру;
Рұқсаттарды тексеру;
Рұқсат етілмеген әрекеттерді бұғаттау;
Рөлдер арасындағы құқықтар иерархиясын ұйымдастыру;
Пайдаланушылардың әрекеттерін тіркеу;
Audit Log журналын жүргізу;
Қателерді өңдеу;
JUnit 5 арқылы жүйені тестілеу.

GitHub — жобаның кодын сақтау және басқару.

13. Күтілетін нәтиже
Әр пайдаланушы тек өзіне берілген құқықтарды пайдалана алады. Ал жүйе барлық әрекеттерді тіркеп, олардың тарихын сақтайды.
