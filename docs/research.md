Research — RBAC кітапханасы және аудит журналы

Орындаған: Амангелді Аяжан

1. Жүйенің сипаттамасы

RBAC — пайдаланушылардың жүйедегі құқықтарын рөлдер арқылы басқару әдісі.

Жүйеде әкімші, менеджер және қарапайым пайдаланушы сияқты рөлдер болады. Әр рөлге белгілі бір рұқсаттар беріледі. Жүйе пайдаланушының құқығын тексеріп, рұқсатсыз әрекеттерді бұғаттайды.

Аудит журналы әрбір рұқсат тексеруін және жүйедегі маңызды әрекеттерді тіркейді. Жобаның мақсаты — ақпаратты қорғау және пайдаланушылардың әрекеттерін бақылау.

2. Жүйенің қатысушылары (Actors)

1. Әкімші (Admin)

* Пайдаланушыларды тіркейді.
* Рөлдер мен рұқсаттарды басқарады.
* Аудит журналын қарайды.

2. Пайдаланушы (User)

* Жүйеге кіреді.
* Өз рөліне сәйкес әрекеттерді орындайды.

3. Қауіпсіздік жүйесі (Security System)

* Пайдаланушының рөлін тексереді.
* Рұқсатсыз әрекеттерді бұғаттайды.
* Әр тексеруді журналға жазады.

3. Функционалдық талаптар

1. Пайдаланушыларды тіркеу.
2. Пайдаланушыларға рөл тағайындау.
3. Рөлдер мен рұқсаттарды басқару.
4. Рөлдер иерархиясын құру.
5. Пайдаланушының құқықтарын тексеру.
6. Рұқсатсыз әрекеттерді бұғаттау.
7. Әр рұқсат тексеруін аудит журналына жазу.
8. Аудит журналын қарау.

4. Функционалдық емес талаптар

* Қауіпсіздік: ақпаратты қорғау.
* Сенімділік: жүйенің дұрыс жұмыс істеуі.
* Жылдамдық: рұқсаттарды тез тексеру.
* Ыңғайлылық: жүйені оңай пайдалану.
* Деректерді сақтау: ақпаратты жоғалтпау.

5. Жүйенің негізгі ережелері

1. Әр пайдаланушының жеке ID нөмірі болады.
2. Әр пайдаланушыға рөл беріледі.
3. Әр рөлдің өз рұқсаттары болады.
4. Жоғары деңгейдегі рөлдерге қосымша құқықтар берілуі мүмкін.
5. Пайдаланушы тек рұқсат етілген әрекеттерді орындайды.
6. Әр рұқсат тексеруі журналға тіркеледі.

6. Java бағдарламасындағы негізгі кластар

Класс	Міндеті
User	Пайдаланушы туралы ақпарат
Role	Рөлдерді сақтау
Permission	Рұқсаттарды сақтау
RoleManager	Рөлдерді басқару
RoleHierarchy	Рөлдер иерархиясы
AccessControl	Құқықтарды тексеру
AuditLog	Тексерулерді журналға жазу
SecuritySystem	Қауіпсіздікті басқару

7. Қолданылатын технологиялар

* Java — бағдарламалау тілі.
* Maven — жобаны және кітапханаларды басқару.
* JUnit 5 — бағдарламаны тестілеу.
* GitHub — кодты сақтау және өзгерістерді бақылау.
